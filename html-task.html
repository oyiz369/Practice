🎨 Bloom & Co. — Creative Studio HTML / CSS Assignment

📋 Project Brief

Objective: Recreate a beautiful, multi-section marketing page for a creative studio. You will be given a completed reference file (see the end of this document). Your job is to rebuild it from scratch or modify it heavily while following the task list below. Focus on semantic HTML, modern CSS layout (Flexbox / Grid), and polished visual design.

🟢 Starter Tasks Core Structure

These tasks ensure you understand the basic skeleton and content flow.

  1. Semantic HTML: Build the page structure using only semantic HTML5 elements (<header>, <nav>, <main>, <section>, <footer>). Do not use <div> for everything!
  2. Hero Section: Create the main hero area with a large heading, a paragraph, and two call-to-action buttons. Make sure the heading uses a mix of normal and italic text (e.g., “Crafting beautiful digital experiences”).
  3. Services Section: Create a 4‑column card layout displaying the services (Brand Identity, Web Design, etc.). Each card must have an icon, a title, and a short description.
  4. Navigation: Build a horizontal navigation bar with links to “Services”, “Work”, “Testimonials”, and a special “Let’s talk” button style.
  5. Footer: Create a footer that includes a copyright notice and a row of social media icon links.

🧠 Intermediate Tasks Styling & Layout

These tasks focus on making the page look polished and professionally aligned.

  1. Typography System: Import and apply two Google Fonts (e.g., Playfair Display for headings and Inter for body text). Ensure a clear visual hierarchy between H1, H2, H3, and paragraph text.
  2. Color Palette: Implement a custom color palette using CSS Custom Properties (:root). Define variables for: Background, Surface (white cards), Primary Text, Muted Text, Accent Color, and Border Color.
  3. CSS Grid Hero: Lay out the Hero section using CSS Grid to place the text content on the left and a decorative shape / emoji on the right. Make it responsive so it stacks on mobile.
  4. Card Hover Effects: Add smooth transitions to the service cards. On hover, the card should lift slightly (translateY) and change its box-shadow.
  5. Responsive Design: Use media queries to ensure the layout adapts to tablet and mobile screens. The 4‑column cards must become 2 columns on tablet and 1 column on mobile.

🚀 Advanced Challenges UI Polish & Interactivity

These tasks are for students who finish early and want to push their CSS / JS skills further.

  1. Gallery Overlay: Build the “Selected Work” gallery. On hover, a dark overlay with a text label should slide up from the bottom of each image block (using transform and opacity).
  2. Sticky Navigation: Make the main navigation bar stick to the top of the viewport when the user scrolls down (using position: sticky).
  3. Interactive CTA: Style the final Call‑to‑Action section with a dark background. Add a hover effect to the button where the background and text colors invert smoothly.
  4. CSS Animations: Add a subtle “fade‑in‑up” animation to the service cards so they fade and slide into view when the page loads (use @keyframes and animation-delay).
  5. Contact Form (Bonus): Inside the CTA section, replace the single button with a mini 2‑field form (Name + Email) and a “Submit” button. Style the inputs to match the brand’s aesthetic (rounded borders, focus states).

🧩 Hint Sheet

Try to solve it with the Starter hints first. If you are totally stuck, peek at the Intermediate hints. Only look at the Advanced snippets if you are completely blocked!

🟢 Starter Hints

Hint 1 – Semantic HTML Shell:
Start with this exact skeleton before adding content: 
<body>
  <header> <!-- Nav goes here --> </header>
  <main>
    <section id="home"> <!-- Hero --> </section>
    <section id="services"> <!-- Cards --> </section>
    <section id="work"> <!-- Gallery --> </section>
    <section id="testimonials"> <!-- Quotes --> </section>
    <section id="contact"> <!-- CTA --> </section>
  </main>
  <footer> <!-- Copyright + Socials --> </footer>
</body>
Hint 2 – Hero Italic Text:
To get the mixed‑style heading (e.g., Crafting beautiful digital), wrap the word you want italicized in a <span> and give it a class or style it with font-style: italic;.
Hint 3 – The “Cards” Layout:
Instead of using a table, create a <div> container with a class of cards-grid. Inside, put four <div> elements (the cards). Each card contains: an icon (emoji or HTML entity), an <h3> title, and a <p> description.
Hint 4 – Navigation Links:
Wrap your links in a <nav> tag. Use an unordered list <ul> with <li> items for each link. This is more accessible than just using <a> tags in a row. Style the list with list-style: none and use display: flex on the <ul>.

🧠 Intermediate Hints

Hint 6 – Google Fonts:
1. Go to fonts.google.com and search for Inter and Playfair Display.
2. Copy the <link> tag and paste it into the <head> of your HTML.
3. In your CSS: apply font-family: 'Inter', sans-serif; to the body, and font-family: 'Playfair Display', serif; to your h1, h2, h3.
Hint 7 – CSS Variables (Custom Properties):
Put this at the very top of your CSS (under the reset): 
:root {
  --bg: #faf8f5;
  --surface: #ffffff;
  --text: #1e1e2a;
  --text-muted: #5a5a6e;
  --accent: #c47a7a;
  --border: #e8e2da;
}
Use them like this: background-color: var(--bg);
Hint 8 – CSS Grid Hero Section:
To make the text on the left and the illustration on the right: 
.hero {
  display: grid;
  grid-template-columns: 1fr 1fr;
  gap: 4rem;
  align-items: center;
}
For the illustration, just put a large emoji (like 🌸 or ✦) inside a <div> with a background color and border-radius.
Hint 9 – Card Hover Effects:
Use transition on the base state, and transform on :hover: 
.card {
  transition: transform 0.3s ease, box-shadow 0.3s ease;
}
.card:hover {
  transform: translateY(-8px);
  box-shadow: 0 20px 40px rgba(0,0,0,0.1);
}
Hint 10 – Responsive (Media Queries):
Add these at the bottom of your CSS file: 
/* Tablets */
@media (max-width: 800px) {
  .hero { grid-template-columns: 1fr; }
  .cards-grid { grid-template-columns: 1fr 1fr; }
}
/* Mobile */
@media (max-width: 500px) {
  .cards-grid { grid-template-columns: 1fr; }
  header { flex-direction: column; }
}

🚀 Advanced Hints

Hint 11 – Gallery Overlay Sliding Up:
Use position: relative on the parent, and position: absolute on the label. 
.gallery-item {
  position: relative;
  overflow: hidden;
}
.gallery-item .label {
  position: absolute;
  bottom: 0;
  left: 0;
  right: 0;
  transform: translateY(100%);
  transition: transform 0.3s ease;
}
.gallery-item:hover .label {
  transform: translateY(0);
}
Hint 12 – Sticky Navigation:
You don’t need JavaScript! Apply this to your <header>: 
header {
  position: sticky;
  top: 0;
  background-color: var(--bg);
  z-index: 100;
}
Hint 13 – Fancy CTA Button Hover:
If your CTA section has a dark background, make the button white. On hover, swap them: 
.cta-box .btn {
  background: white;
  color: black;
  transition: 0.3s ease;
}
.cta-box .btn:hover {
  background: transparent;
  color: white;
  border-color: white;
}
Hint 14 – Fade‑in‑up Animation on Load:
Define the keyframes, then apply to the cards with staggered delays: 
@keyframes fadeUp {
  0% { opacity: 0; transform: translateY(30px); }
  100% { opacity: 1; transform: translateY(0); }
}
.card {
  animation: fadeUp 0.6s ease forwards;
  opacity: 0;
}
.card:nth-child(1) { animation-delay: 0.1s; }
.card:nth-child(2) { animation-delay: 0.2s; }
.card:nth-child(3) { animation-delay: 0.3s; }
.card:nth-child(4) { animation-delay: 0.4s; }
🧰 Stuck on a Specific Problem?
• Grid items are squished: Use 1fr or minmax() in grid-template-columns.
• Flex items won’t center: On the parent: display: flex; justify-content: center; align-items: center;
• Padding breaks widths: Add box-sizing: border-box; to your global reset (*).
• Hover effects are instant: You forgot transition on the base state.
• Google Fonts aren’t loading: Check the <link> tag is in the <head> and you have internet.
